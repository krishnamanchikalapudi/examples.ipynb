# Large Language Models (LLM)

## What is Large Language Models (LLM)?
Large Language Models (LLMs) are a class of foundation models trained on vast datasets, enabling them to understand, generate, and reason across natural language and other content formats. Open LLMs extend this capability by promoting transparency, collaboration, and customization—empowering teams to Invent and Simplify solutions while maintaining Ownership of their AI stack. 


## What is LangChain?
LangChain is an open source orchestration framework for the development of applications using LLMs. Available in both Python- and JavaScript-based libraries, LangChain’s tools and APIs simplify the process of building LLM-driven applications like chatbots and virtual agents. 


## What is Ollama?
A tool that facilitates running LLM locally on personal devices, providing the ability to load and interact with AI models such as Llama 3.2. 

## What is Small Language Models (SLMs)?
SLMs are more efficient, requiring less computational power and tailored for specific tasks.


## What is Vector Databases?
Specialized databases used to store and query vector representations of data, particularly useful in AI applications like semantic search, where similarities between data points are computed based on their vector representations.
